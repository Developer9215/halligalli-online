# 할리갈리 온라인 (Halli Galli)

여러 명이 각자 스마트폰으로 접속해서 즐기는 실시간 온라인 할리갈리입니다. 카드는 화면을 위로 스와이프해서 넘기고, 과일 합이 5가 되면 종 버튼을 먼저 눌러야 합니다.

- 서버: Node.js + Express + Socket.io (카드 분배, 차례 진행, 매치 판정, 페널티를 서버가 전부 관리)
- 클라이언트: React + Vite, 스와이프 제스처로 카드 넘기기 + 큰 종 버튼

## 게임 방법

- 2~8명, 방장이 로비에서 "게임 시작"을 누르면 카드가 균등하게 나뉩니다 (자기 카드는 절대 미리 볼 수 없음).
- 자기 차례가 되면 화면의 카드를 위로 스와이프해서 한 장을 넘깁니다. 넘긴 카드는 모두에게 공개됩니다.
- 모든 플레이어의 "가장 최근에 넘긴 카드"들을 같은 과일끼리 더해서 정확히 5가 되면, 누구든（넘긴 사람 포함) 🔔 버튼을 가장 먼저 눌러야 합니다.
- 정확했다면 그 순간 테이블에 나와 있는 모든 카드를 가져갑니다. 틀렸다면 자기 카드 중 위에서부터 한 장씩 다른 사람 전원에게 나눠줍니다.
- 카드가 없는 사람은 자기 차례에 자동으로 패스합니다.
- 카드를 전부 모은 사람이 승리합니다.

## 공정한 판정 방식 (네트워크 환경)

실물 종처럼 정확한 물리적 동시 판정은 불가능하므로, 서버에 가장 먼저 도착한 종치기 요청을 우선 처리합니다. 또한 클라이언트가 마지막으로 본 상태 번호(`revealGen`)를 함께 보내, 이미 다른 사람이 가져간 뒤 "한 박자 늦게" 누른 경우에는 페널티 없이 무시하고, 실제로 그 순간 조합이 틀렸을 때만 페널티를 줍니다.

## 프로젝트 구조

```
halligalli/
  server/   # Socket.io 게임 서버
  client/   # React 모바일 UI (스와이프 카드 + 종 버튼)
```

## 로컬 실행

```
cd halligalli
npm install
npm run dev
```

- 서버: http://localhost:3003
- 클라이언트: http://localhost:5175

## 배포 (Render)

GitHub 저장소를 만들고 Render에서 "New Web Service"로 연결하면 됩니다 (레포에 포함된 `render.yaml`을 쓰면 Build/Start 명령이 자동 설정됩니다).
